# AI Enhanced Adaptable Tutor

A front-end prototype for an AI-enhanced, adaptable tutoring platform for higher-education courses.

## What is included

- Student studio for pre-lecture learning, practice, feedback, tutor chat, mastery, and attempt history
- Instructor console for assessment preview, student question aggregation, mastery analytics, and model steering
- Platform blueprint view covering architecture, data entities, and rollout phases
- Schedule-agnostic product framing with a Monday / Wednesday course example

## Run locally

Open `index.html` in a browser.

No build step or package install is required.
