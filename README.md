# AI Enhanced Adaptable Tutor

A front-end prototype for an AI-enhanced, adaptable tutoring platform for higher-education courses. The prototype now reflects a framework-first plan: keep the tutor engine separate from the LLM, make course content and model providers replaceable, and build the MVP as a modular monolith.

## What is included

- Student tutor view with concept-level mastery, source authority tiers, and adaptive next-step decisions
- Instructor console for course configuration, AI steering, assessment approval, and class signals
- Tutor engine view showing the orchestrator, knowledge retrieval, teaching strategy, model adapter, and mastery update flow
- Build blueprint view covering repository structure, data entities, modular interfaces, and staged MVP rollout
- Schedule-agnostic product framing for M/W, M/W/F, T/Th, and custom course calendars

## Run locally

Open `index.html` in a browser.

No build step or package install is required.
