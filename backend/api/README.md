# Backend API

FastAPI route files go here.

Example routes:

- `GET /courses`
- `POST /courses`
- `POST /documents/upload`
- `POST /tutor/message`
- `POST /practice/answer`
- `GET /students/{student_id}/mastery`
- `GET /assessments/{assessment_id}/review`

This folder receives requests from the React frontend and calls the backend services.
